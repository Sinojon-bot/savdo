ANDROID APK (ихтиёрӣ)
=====================

Барои файли .apk (скачать-файл ба одамон):

1) Android Studio насб кунед: https://developer.android.com/studio
2) Дар папкаи mobile:
   npm install
   npm run build:web
   npx cap add android
   npm run cap:sync
   npm run open:android
3) Дар Android Studio: Build → Build APK(s)
4) Файли APK-ро ба одамон фиристед.

Бе Android Studio: саҳифаи /download — насб аз Chrome
(мисли барнома, иконка дар экран).

iPhone: Safari → Ба экрани асосӣ (бе App Store).
