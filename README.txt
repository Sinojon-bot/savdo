Savdo — скачать как приложение

КОМПЮТЕР
1. Дважды: НАСБ-БА-РАБОЧИЙ-СТОЛ.bat
2. На рабочем столе появится «Savdo»
3. Откройте — как программа (без адресной строки)

Или: OPEN-APP.bat / START.bat → [1]

ТЕЛЕФОН (русский Android / iPhone)
1. Компьютер держите включённым с START.bat
2. По Wi‑Fi откройте IP-адрес (Настройки → скопировать)
3. Скачать:
   Android: Chrome → ⋮ → «Установить приложение»
   iPhone: Safari → Поделиться → «На экран „Домой“»

Это ОДНО приложение — не три разных.
